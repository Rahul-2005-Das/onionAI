# 🧅 OnionIQ

### AI-Assisted Onion Quality Assessment & Grading

OnionIQ is a mobile-friendly prototype developed for Smart India Hackathon Problem Statement 26031.

It aims to make onion quality assessment more structured, consistent and digitally documented.

## 🎯 Problem Statement

**PS ID: 26031**

Quality assessment and grading of onions are often subjective and vary across procurement centers, resulting in disputes and inconsistencies.

## 💡 Proposed Solution

OnionIQ provides an AI-assisted workflow to:

- Capture or upload onion images
- Assess onion quality
- Identify quality-related defects
- Calculate Grade A and URS percentages
- Allow human verification
- Generate digital quality reports
- Maintain assessment history

## ✨ Key Features

- 🤖 AI-assisted onion quality assessment
- 📊 Grade A & URS estimation
- 👤 Human verification
- 🌐 English, Bengali & Hindi
- 👨‍🌾 Farmer-friendly interface
- 📄 Digital quality report
- 📚 Assessment history
- 🔊 Voice assistance
